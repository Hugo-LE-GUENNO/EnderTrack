🔧 Aide G-code

Basic commands:

  • G28 - Home all axes
  • G0 X10 Y5 - Rapid move
  • G1 X10 Y5 F1000 - Linear move
  • G90 - Absolute mode
  • G91 - Relative mode

System commands:

  • M115 - Firmware info
  • M114 - Current position
  • M300 - Beep
  • M999 - Reset/Restart
  • M112 - Emergency stop
