# EnderTrack — Python Plugin Guide

## Objets disponibles dans le contexte

Dans les plugins SECTIONS → toujours via `ctx.` :
```python
ctx.stage    ctx.cam    ctx.light    ctx.lists    ctx.config
ctx.log()    ctx.update_output()    ctx.append_table_row()
```

Dans le python-editor → directement :
```python
stage    cam    light    lists    np    cv2
```

## ctx.config — Variables globales EnderTrack

```python
config = ctx.config

# Position actuelle du stage
config['position']                         # {'x': 10.0, 'y': 20.0, 'z': 0.0}

# Limites des axes (depuis firmware M211 — disponibles si stage connecté)
config['coordinateBounds']                 # {'x': {'min': -27, 'max': 220}, 'y': ..., 'z': ...}
config['coordinateBounds']['x']['min']     # float mm
config['coordinateBounds']['x']['max']
config['coordinateBounds']['y']['min']
config['coordinateBounds']['y']['max']
config['coordinateBounds']['z']['min']
config['coordinateBounds']['z']['max']

# Dimensions du plateau
config['plateauDimensions']                # {'x': 247, 'y': 231, 'z': 250}

# Vitesses
config['feedrate']                         # int mm/min (vitesse XY actuelle)
config['zSpeed']                           # float mm/s (vitesse Z actuelle)
config['maxFeedrate']                      # int mm/min (max firmware)
config['maxZSpeed']                        # float mm/s (max firmware)

# Caméras connectées
config['cameras']                          # liste de dicts
config['cameras'][0]['sensor']             # ex: 'imx477'
config['cameras'][0]['pixel_size']         # float µm/px
config['cameras'][0]['resolution']         # [w, h]
config['cameras'][0]['preview_resolution'] # [w, h]
config['cameras'][0]['rotation']           # 0/90/180/270

# Lumières connectées
config['lights']                           # liste de dicts
```

Exemple typique :
```python
bounds = ctx.config.get('coordinateBounds', {})
x_min = bounds.get('x', {}).get('min', 0)
x_max = bounds.get('x', {}).get('max', 100)
y_min = bounds.get('y', {}).get('min', 0)
y_max = bounds.get('y', {}).get('max', 100)
```

## Structure d'un plugin SECTIONS

Un plugin = un fichier `.py` dans `plugins/<id>/`.
`SECTIONS` définit les onglets affichés dans l'UI.

### Onglets disponibles

| Clé          | Emplacement UI       | Style                              |
|--------------|----------------------|------------------------------------|
| `navigation` | Onglet Navigation    | Boutons / contrôles directs  → `navPluginZone`      |
| `settings`   | Onglet Settings      | **Accordéon** (titre = NAME) → `configPluginZone`   |
| `waypoints`  | Onglet Waypoints     | Gestion de positions         → `listsPluginZone`    |
| `automation` | Onglet Automation    | Scénarios, séquences longues  → `automationPluginZone`|

Chaque onglet a `inputs` et `outputs` :

```python
SECTIONS = {
    "navigation": {
        "inputs":  [ ...boutons, sliders... ],
        "outputs": [ ...logs, tables, values... ]
    },
    "settings": {
        # Affiché en accordéon — titre = NAME du plugin
        "inputs":  [ ...sliders, dropdowns, inputs... ],
        "outputs": []
    },
    "automation": {
        "inputs":  [ ...boutons de lancement de séquence... ],
        "outputs": [ ...tables de résultats, logs... ]
    }
}
```

### Inputs

```python
{"type": "button",   "label": "Go",   "action": "nom_fonction"}
{"type": "button",   "label": "Go",   "action": "nom_fonction", "style": "primary"}
{"type": "slider",   "id": "speed",   "label": "Vitesse", "min": 0, "max": 100, "default": 50}
{"type": "input",    "id": "name",    "label": "Nom",     "default": "", "input_type": "text"}
{"type": "input",    "id": "val",     "label": "Val",     "default": 0,  "input_type": "number"}
{"type": "dropdown", "id": "mode",    "label": "Mode",    "options": ["A", "B", "C"]}
```

### Outputs

```python
{"type": "value", "id": "status",  "label": "Statut"}
# → ctx.update_output("status", "OK")

{"type": "log",   "id": "log",     "label": "Log"}
# → ctx.update_output("log", "message")

{"type": "table", "id": "history", "label": "Historique", "columns": ["X", "Y", "Z"]}
# → ctx.append_table_row("history", ["1.0", "2.0", "0.0"])
```

### Actions

```python
def mon_action(ctx, params):
    # params contient les valeurs de tous les inputs
    speed = params.get('speed', 50)
    name  = params.get('name', '')
    return {'success': True}
```

## Exemple complet — scan grid avec capture

```python
NAME    = "Scan Grid"
VERSION = "1.0.0"

SECTIONS = {
    "settings": {
        "inputs": [
            {"type": "slider",   "id": "steps", "label": "Steps",      "min": 2, "max": 10, "default": 3},
            {"type": "slider",   "id": "size",  "label": "Size (mm)",  "min": 5, "max": 100, "default": 30},
            {"type": "dropdown", "id": "fmt",   "label": "Format",     "options": ["tiff", "jpg", "png"]},
        ],
        "outputs": []
    },
    "automation": {
        "inputs": [
            {"type": "button", "label": "▶ Lancer le scan", "action": "run", "style": "primary"},
        ],
        "outputs": [
            {"type": "table", "id": "log", "label": "Positions",
             "columns": ["X", "Y", "File"]}
        ]
    }
}


def run(ctx, params):
    stage = ctx.stage
    if not stage:
        return {'success': False, 'error': 'Stage non connecté'}

    steps = int(params.get('steps', 3))
    size  = float(params.get('size', 30))
    fmt   = params.get('fmt', 'tiff')
    step  = size / (steps - 1) if steps > 1 else size

    ctx.lists.delete_list('Scan')
    ctx.lists.new_list('Scan', color='#4ae290', pinned=True)
    ctx.light.on(intensity=0.8)

    for i in range(steps):
        for j in range(steps):
            x, y = i * step, j * step
            stage.move_absolute(x, y, stage.position['Z'])
            stage.finish_moves()
            path = f'/tmp/scan_{i}_{j}.{fmt}'
            ctx.cam.capture(path=path)
            ctx.lists.add(x, y, stage.position['Z'], name=f'pt_{i}_{j}', list='Scan')
            ctx.append_table_row('log', [f"{x:.1f}", f"{y:.1f}", path])

    ctx.light.off()
    return {'success': True}
```
